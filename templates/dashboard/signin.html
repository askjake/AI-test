Local bootstrap access

For the clone owner’s setup or recovery use only. This is not the normal sign-in path.

On the machine that owns this clone, copy a role-specific credential without displaying it:

./install.sh access --role viewer --copy
./install.sh access --role operator --copy

In Windows PowerShell, use ./install.ps1 with the same arguments.

Credentials are exchanged for an opaque HttpOnly session and are not stored by this page.

Access levels

Viewer

Inspect projects, live display, reports, screenshots, and logs.

Operator

Create, edit, and save projects and specifications; run guarded refinement and approved target preflight; start or stop authorized project work.

Bootstrap and identity-provider settings remain local-owner administration tasks. Browser sessions cannot choose or promote their own role.
